## 本地起后端

```bash
cd backend
python -m venv ../.venv            # 或用已有 venv
../.venv/Scripts/pip install -r requirements-dev.txt   # Windows
# source ../.venv/bin/activate && pip install -r requirements-dev.txt   # Linux

# 需要一个 PostgreSQL。没有的话可以直接用 SQLite 跑起来：
export WARDROBE_DATABASE_URL="sqlite+aiosqlite:///./dev.db"
export WARDROBE_JWT_SECRET="dev-only-change-me-at-least-32-bytes-long"
export WARDROBE_BOOTSTRAP_USERNAME=naonao
export WARDROBE_BOOTSTRAP_PASSWORD=devpassword
export WARDROBE_ALLOW_REGISTRATION=true

alembic upgrade head
uvicorn app.main:app --reload --port 8000
```

接口文档：http://127.0.0.1:8000/api/docs

### 跑测试

```bash
cd backend
../.venv/Scripts/python -m pytest -q
```

测试跑在**内存 SQLite** 上，不需要 PostgreSQL。

## 构建镜像

```bash
# 在项目根目录
docker compose build

# 国内网络可换源
PIP_INDEX_URL=https://mirrors.aliyun.com/pypi/simple/ \
NPM_REGISTRY=https://registry.npmmirror.com \
docker compose build
```

镜像源通过 **构建参数** 传入，不写死在 Dockerfile 里（`ENV PIP_INDEX_URL` 会污染运行期环境）。

## 数据模型约定

### 用户隔离（关键）

- 所有业务表**必须**带 `owner_id`（批次 2 起）。
- 查询一律走 API 层注入的当前用户，强制 `WHERE owner_id = :uid`，不靠业务代码自觉。
- 共享功能尚未实现，但表结构预留：未来加 `visibility` 字段与关联表即可，不需要迁移历史数据。

### 时间戳

- 所有 `DateTime` 列一律 `timezone=True`。
- ⚠️ **SQLite 读回来的 datetime 是 naive 的**，PG 是 aware 的。任何比较前必须过
  `app.core.time.as_aware()`，否则在 SQLite 上测试通过、在 PG 上反而没事，或者反过来炸。

### 令牌

| | 存放 | 有效期 | 用途 |
|---|---|---|---|
| access token | 前端内存 | 30 分钟 | 每个请求的 `Authorization: Bearer` |
| refresh token | 前端 localStorage | 30 天 | 换新 access token；**库里只存 sha256 摘要** |

- **轮换**：每次刷新都吊销旧会话、签发新会话。旧令牌重放直接 401。
- **改密**：吊销该用户全部会话，强制所有设备重新登录。
- **设备管理**：`user_sessions` 一行 = 一台设备，可在设置页单独吊销。

## 已知取舍 / 后续加固

1. **refresh token 放在 localStorage**，理论上可被 XSS 读取。自托管单用户场景可接受。
   上 https 后建议改为 httpOnly + SameSite=Strict 的 Cookie（需同步调整 CORS 与 CSRF 策略）。
2. **X-Forwarded-For 直接信任首段**。仅在反代（Lucky / nginx）可信的前提下成立；
   若 API 直接暴露公网需要收紧。
3. 注册默认关闭。开放注册前应加邮箱验证或邀请码。

## 构建环境提示（本机）

- 本机（Windows）**没有 Docker**，本地阶段用 venv + npm 直接跑。
- 沙箱代理会拦清华源（pip 拿到 403），直连时用阿里云源可用：
  `-i https://mirrors.aliyun.com/pypi/simple/`，并需去掉 `http_proxy`/`https_proxy` 环境变量。
